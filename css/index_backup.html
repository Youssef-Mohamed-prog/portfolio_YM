Data Visualization

Numbers alone rarely convince anyone. I design charts and visual layouts that make trends and comparisons immediately obvious, choosing the right chart type for the right question. Every visualization is built to answer a question in seconds.

Dashboard Development

I build interactive dashboards that bring multiple KPIs, filters, and views together in one place, so decision-makers can explore the data themselves instead of waiting for a new report every time something changes.

Data Storytelling & Insights
